**1. (B5, MUST) Stop feeding untrusted bytes to `restoreGeometry`.**
Today `cd99d36` range-checks only the frame rect at offset 8. `restoreGeometry` still applies the rest of the 66-byte blob unchecked, including the v3 restored-geometry rect at offset 50. Single-bit flips there (bits 465–472 and 497–505) give SIGSEGV on offscreen (the real app crashed 8 of 8 launches) and a 16,777,215 px window on xcb.

Fix:
- **Store a plain record.** `_save_window_geometry` writes JSON `{"version": 2, "x": int, "y": int, "width": int, "height": int, "maximized": bool}`, using the normal (non-maximized) geometry. It stays atomic: write a temp file, `os.replace`, and remove the temp file on failure.
- **Validate the record.** `_restore_window_geometry` reads it inside one `try/except Exception` and checks every field on its own:
  - ints (not bool, not float);
  - x and y within ±2^30;
  - width and height within `1..QWIDGETSIZE_MAX` and at most 2^30;
  - `maximized` a real bool.
  Any invalid value falls back to the default geometry (and logs once).
- **Apply it without `restoreGeometry`.** Use `resize` and `move`, then `showMaximized` on show if maximized.
  - Clamp the size to the union of all screens' `availableGeometry()`. If the saved size is larger, use the default size, or the clamped size (log the choice).
  - Keep the B2 behavior: the title-bar grab ends inside a screen's available area (reuse `_title_bar_on_a_screen` / `_pull_title_bar_on_screen`).
- **Old files.** An old `{"geometry": "<base64 blob>"}` file is **ignored** (default geometry, then rewritten as a record on quit). Remove `restoreGeometry` from the restore path entirely. `_saved_frame` may go, or stay only if still used.
- **Safety net.** After applying, if `win.size()` exceeds the union of `availableGeometry()` in either dimension, reset to the default size and move to (0, 0).
