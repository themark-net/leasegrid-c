# U4 — IA (recovery-copy on the CrashPlan shell)

**Cite:** tip `4e1e6bd` · P1 folders-first · issue #15

## Places

| Place | Role |
|-------|------|
| **Folders** | Home after join. Offer disk pie stays here. **Add folder** stays the folders CTA. **Restore from recovery key…** starts the recovery-copy path. |
| **More → Recovery** | Threat HITL, **Restore to Folders** (primary), **Export recovery key…** (dual ACK). |
| **More → Credit** | Unchanged. Hidden unless `LEASEGRID_GATED`. |
| **More → Settings** | Unchanged. Payment lecture only when gated. |
| Join page | Short. **Import recovery key instead…** is the pre-join recovery-copy entry. Threat copy is not a lecture on this page. |

Restore always returns to the **Folders** list.
