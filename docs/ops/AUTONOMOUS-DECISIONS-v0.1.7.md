# Autonomous decisions — v0.1.7 batch

Format: choice | alternatives | why

- Lead implements items in order on this worktree | parallel sub-agents in sibling worktrees | items share src/leasegrid_sync and tests, commits must stay ordered, and the drop-in forbids sibling directories
- Signals call MainWindow.quit() directly | route them through the invite-close dialog | a service manager must not wait on a dialog nobody can click
- Windows process test covers SIGBREAK only | also send CTRL_C_EVENT or SIGTERM | SIGTERM is TerminateProcess, SIGHUP does not exist, and CTRL_C_EVENT hits the whole console. The handler still installs SIGINT and SIGBREAK.
- Windows daemon tree kill is CTRL_BREAK_EVENT then taskkill /T /F | a job object, or TerminateProcess on the leader only | taskkill /T /F is the tree kill Windows actually ships; the group flag is set only on daemons popen_hidden starts
- A second --join while already joined shows "Leasegrid Sync is already on a friendnet. This invite was not opened." and drops the invite | auto-join, or open a second grid | there is no add-another-grid path
- POSIX handoff connects to the QLocalServer socket in the temp dir | an in-process QLocalSocket | a QCoreApplication in the caller would break later UI tests. Windows sends through a helper process so the invite stays on stdin
- display_path also masks the not-a-folder banner, the unexpected-error log line, the last-export line, and the "Tahoe node found" line | mask only Settings, the bug report, and the missing-folder banner | those are paths a person sees, and the account name is the part to hide. Editable path fields stay absolute
- Maximized save converts normalGeometry from the client origin to the frame origin win.x()/move() use | save geometry() or the raw normalGeometry | those two origins differ by the frame margin, and mixing them walks the window on every maximize cycle
- Scrub rule: a token matches WORMHOLE_CODE_RE inside text; a dot is a boundary unless a digit precedes it; every segment's letter prefix must be a PGP word (trailing digits allowed); all() not any(). 2-adult-tiger is redacted by design | keep only exact two-word codes, or use any() | the backend accepts 7-guitarist-revenge2, and any() would hide mixed real-word tokens such as 7-guitarist-side
- The 40+ token check is awk in the old rule's pipeline slot | one sed substitution | a digit or the other letter case can sit past the first 40 characters, which one sed branch does not see
- Fix round 1: the lead implements items 1–3 in order on this worktree | one sub-agent per item in a sibling worktree | the drop-in allows only this worktree and /tmp, and all three items edit app.py
- POSIX handoff listens in a 0700 directory the process can lstat, not the world temp socket | keep tempfile.gettempdir()/leasegrid-sync-<hash> | a listener on that shared path received the invite and the CLI still returned 0
- Reject an empty or oversized invite locally, then take the lock check, and only then look up or connect the endpoint | call the lock check before the length check | neither step sends bytes; the lock check still runs before any socket or pipe call
- When the fallback directory is too long for the full hashed name, use the longest SHA-256 hex prefix of at least 16 characters that keeps the path under 100 bytes | always use the 47-character name, or skip the handoff | macOS CI TMPDIR plus the full name can pass the 100-byte cap the drop-in sets
- Fix round 2: the lead implements items 1–10 in order in this worktree | one sub-agent per item in a sibling worktree | the drop-in allows only this worktree and /tmp, several items edit app.py, and each commit must fast-forward the same branch
- Snake_case keep is a sed -E protect/restore around the v0.1.6 `{40,}` rule, using a SOH byte | a 6th strict xfail that over-redacts, or any awk | SOH cannot occur in a tahoe log line, GNU and BSD sed -E both have intervals, and the leak tests still have to pass
- A PID-less lock uses QLockFile staleLockTime 2000 ms and is never unlinked here; younger than 2s is refused | removeStaleLockFile, or an atomic rename | a 5s-old lock still had 34/1000 double holders when this process renamed the file, and a dead PID still recovers at once with staleLockTime 2000
- Join handoff keeps at most 8 pending sockets, aborts the rest, and drops an idle socket after 2s | unbounded accept, or a larger cap | about 354 rapid connections segfaulted the window
- An oversized or empty --join checks the lock and does not send: held shows already-running and exits 1; free prints a short error and exits 1 | return "free" and join | the old free return could join while another instance held the home
- A different handed invite asks with QMessageBox Yes/No, default No | an inline notice, or overwrite | No keeps the text the user already typed, and the question does not contain either invite
- Home masking runs inside SyncError.banner, which every window banner renders | mask only show_join_error and show_folder_error | server, offer, and credit banners also call banner(), and the stored message stays absolute until then
