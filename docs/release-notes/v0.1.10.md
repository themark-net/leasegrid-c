# Leasegrid Sync v0.1.10

Friends-and-family build of Leasegrid Sync, the desktop folder-sync window. The desktop app is the same as v0.1.9; this cut ships the Android hardening for #78 and #80 in source.
The installers are unsigned, so your OS will warn before the first launch.

## Install

| OS | Download | One-liner |
|----|----------|-----------|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04+, Debian 12+, Fedora 36+) | [`Leasegrid_Sync-0.1.10-x86_64.AppImage`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.10/Leasegrid_Sync-0.1.10-x86_64.AppImage) | `chmod +x` it and run it. Needs FUSE (`libfuse2` on Ubuntu). |
| macOS (Intel; Apple Silicon through Rosetta 2) | [`Leasegrid_Sync-0.1.10-macos-x86_64.dmg`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.10/Leasegrid_Sync-0.1.10-macos-x86_64.dmg) | Drag to Applications, then **Open Anyway** (steps below). |
| Windows 10/11 x64 | [`Leasegrid_Sync-0.1.10-win64-setup.exe`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.10/Leasegrid_Sync-0.1.10-win64-setup.exe) | On SmartScreen: **More info → Run anyway**. |
| Windows x64, no setup | [`Leasegrid_Sync-0.1.10-win64.zip`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.10/Leasegrid_Sync-0.1.10-win64.zip) | Unzip and start `leasegrid-sync.exe`. `leasegrid-sync-cli.exe` is the console program, not the window. |

**Checksums:** compare your download with the matching `SHA256SUMS-linux-x86_64`, `SHA256SUMS-macos-x86_64` or `SHA256SUMS-win64` asset on [this release](https://github.com/themark-net/leasegrid-c/releases/tag/v0.1.10) before you run it.

<details>
<summary>macOS: “unidentified developer”: Open Anyway steps</summary>

1. Open the `.dmg` and drag **Leasegrid Sync** onto **Applications**.
2. Double-click **Leasegrid Sync** in Applications. Gatekeeper blocks it (the app is ad-hoc signed, not notarized).
3. Open **System Settings → Privacy & Security** and click **Open Anyway**. It shows for about an hour after the block. Enter your login password.

On macOS 14 and earlier, Control-click the app → **Open** → **Open** instead. Control-click no longer bypasses Gatekeeper on macOS 15.
</details>

## What's new

- Android **Invite**: a paste of about 100 KB that is almost a short code shows *That isn't a join link.* instead of failing, and **Retry** after fixing the field joins the corrected link. Invisible marks copied with a link are dropped; a link with control characters, a space, a short swissnum, an empty tub id or no address is reported as incomplete or asks for the address, and nothing is sent ([#78](https://github.com/themark-net/leasegrid-c/issues/78), [#80](https://github.com/themark-net/leasegrid-c/issues/80), `f4d8e58`, `db08dcc`, `56c8fe9`).
- Android recovery import: a file over 1 MiB, nested too deep, with scrypt settings over the caps, or with bad share counts shows the import card with **Retry**. **Cancel** and back on the import screen stop a running import and save nothing ([#80](https://github.com/themark-net/leasegrid-c/issues/80), `cdeba16`, `65ce6e9`).
- Android error cards no longer show an exception class name (the class goes to the log), **Retry** runs once per tap, a cancelled job no longer clears a newer job's busy state, and the phone app says *shared folder* instead of *friendnet* ([#80](https://github.com/themark-net/leasegrid-c/issues/80), [#84](https://github.com/themark-net/leasegrid-c/issues/84), `65ce6e9`, `df11bea`, `ea9b803`, `113878a`).
- Not in this build: joining from the phone with a short code or QR scan ([#77](https://github.com/themark-net/leasegrid-c/issues/77)). Follow-ups: [#85](https://github.com/themark-net/leasegrid-c/issues/85).
- Everything else is the same as v0.1.9.

## Known issues

- Add folder can return Magic Folder HTTP 500 ([#30](https://github.com/themark-net/leasegrid-c/issues/30), open, parked): the row never says **Up to date**. Mention #30 in your bug report.
- The installers are unsigned, so Gatekeeper and SmartScreen warn. On Windows 11, Smart App Control can block the app and not offer **Run anyway**.
