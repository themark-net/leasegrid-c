# Leasegrid Sync v0.1.11

Friends-and-family build of Leasegrid Sync, the desktop folder-sync window. This cut includes the desktop and Android changes since v0.1.10. There is no APK asset in this release (the Android app file is on hold).
The installers are unsigned, so your OS will warn before the first launch.

## Install

| OS | Download | One-liner |
|----|----------|-----------|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04+, Debian 12+, Fedora 36+) | [`Leasegrid_Sync-0.1.11-x86_64.AppImage`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.11/Leasegrid_Sync-0.1.11-x86_64.AppImage) | `chmod +x` it and run it. Needs FUSE (`libfuse2` on Ubuntu). |
| macOS (Intel; Apple Silicon through Rosetta 2) | [`Leasegrid_Sync-0.1.11-macos-x86_64.dmg`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.11/Leasegrid_Sync-0.1.11-macos-x86_64.dmg) | Drag to Applications, then **Open Anyway** (steps below). |
| Windows 10/11 x64 | [`Leasegrid_Sync-0.1.11-win64-setup.exe`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.11/Leasegrid_Sync-0.1.11-win64-setup.exe) | On SmartScreen: **More info → Run anyway**. |
| Windows x64, no setup | [`Leasegrid_Sync-0.1.11-win64.zip`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.11/Leasegrid_Sync-0.1.11-win64.zip) | Unzip and start `leasegrid-sync.exe`. `leasegrid-sync-cli.exe` is the console program, not the window. |

**Checksums:** compare your download with the matching `SHA256SUMS-linux-x86_64`, `SHA256SUMS-macos-x86_64` or `SHA256SUMS-win64` asset on [this release](https://github.com/themark-net/leasegrid-c/releases/tag/v0.1.11) before you run it.

<details>
<summary>macOS: “unidentified developer”: Open Anyway steps</summary>

1. Open the `.dmg` and drag **Leasegrid Sync** onto **Applications**.
2. Double-click **Leasegrid Sync** in Applications. Gatekeeper blocks it (the app is ad-hoc signed, not notarized).
3. Open **System Settings → Privacy & Security** and click **Open Anyway**. It shows for about an hour after the block. Enter your login password.

On macOS 14 and earlier, Control-click the app → **Open** → **Open** instead. Control-click no longer bypasses Gatekeeper on macOS 15.

## What's new

- Android **Invite** accepts the short code from **Share invite** in the same field as the full join link. A short code is no longer refused. If the code expired, was not accepted, the invite relay could not be reached, or nobody answered, the screen says so and **Retry** tries again. The field is kept. Pasting the full join link still joins and skips that step ([#77](https://github.com/themark-net/leasegrid-c/issues/77)).
- A Tahoe folder that is missing, empty, or not a client names a plain next step: move that folder aside, point Sync at a running client, or paste a join link or short code. The folder path stays in the message. A conflict copy left in the folder shows Conflict and names the file. A synced folder whose directory was removed shows Missing, with a next step, until that directory is back.
- While Sync is open, a friendnet that cannot be reached, or storage that drops, shows what is wrong and a next step. A join or recovery import that cannot reach the friendnet removes the node it just created, so a corrected invite or key can be tried. A node that was already on this computer stays. Offering disk on a loopback address listens on that address only.
- On Android, an add when the phone has no room says there is not enough free space and does not upload. A download the phone cannot save, or a file the phone cannot read for an add, says the phone would not allow it and to check storage permission, then **Retry**. List and remove errors no longer say "download" ([#85](https://github.com/themark-net/leasegrid-c/issues/85)). A recovery file name is read from the app files folder. A path that leaves that folder is refused, and the outside file is not read ([#26](https://github.com/themark-net/leasegrid-c/issues/26)).
- Tests pass on Windows and macOS again ([#86](https://github.com/themark-net/leasegrid-c/issues/86)); desktop behaviour unchanged by that fix.

## Known issues

- Add folder can return Magic Folder HTTP 500 ([#30](https://github.com/themark-net/leasegrid-c/issues/30), open, parked): the row never says **Up to date**. Mention #30 in your bug report.
- The installers are unsigned, so Gatekeeper and SmartScreen warn. On Windows 11, Smart App Control can block the app and not offer **Run anyway**.
