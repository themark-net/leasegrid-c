# Leasegrid Sync v0.1.12

Friends-and-family build of Leasegrid Sync, the desktop folder-sync window. This cut includes the desktop and Android changes since v0.1.11.

**There is no Android APK in this release.** The Android changes below are in the source only. Only the desktop installers are attached. Third party notices for the Android scanner libraries are in [`android/THIRD_PARTY_NOTICES.md`](https://github.com/themark-net/leasegrid-c/blob/main/android/THIRD_PARTY_NOTICES.md).

The installers are unsigned, so your OS will warn before the first launch.

## Install

| OS | Download | One-liner |
|----|----------|-----------|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04+, Debian 12+, Fedora 36+) | [`Leasegrid_Sync-0.1.12-x86_64.AppImage`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.12/Leasegrid_Sync-0.1.12-x86_64.AppImage) | `chmod +x` it and run it. Needs FUSE (`libfuse2` on Ubuntu). |
| macOS (Intel; Apple Silicon through Rosetta 2) | [`Leasegrid_Sync-0.1.12-macos-x86_64.dmg`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.12/Leasegrid_Sync-0.1.12-macos-x86_64.dmg) | Drag to Applications, then **Open Anyway** (steps below). |
| Windows 10/11 x64 | [`Leasegrid_Sync-0.1.12-win64-setup.exe`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.12/Leasegrid_Sync-0.1.12-win64-setup.exe) | On SmartScreen: **More info → Run anyway**. |
| Windows x64, no setup | [`Leasegrid_Sync-0.1.12-win64.zip`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.12/Leasegrid_Sync-0.1.12-win64.zip) | Unzip and start `leasegrid-sync.exe`. `leasegrid-sync-cli.exe` is the console program, not the window. |

**Checksums:** compare your download with the matching `SHA256SUMS-linux-x86_64`, `SHA256SUMS-macos-x86_64` or `SHA256SUMS-win64` asset on [this release](https://github.com/themark-net/leasegrid-c/releases/tag/v0.1.12) before you run it.

<details>
<summary>macOS: “unidentified developer”: Open Anyway steps</summary>

1. Open the `.dmg` and drag **Leasegrid Sync** onto **Applications**.
2. Double-click **Leasegrid Sync** in Applications. Gatekeeper blocks it (the app is ad-hoc signed, not notarized).
3. Open **System Settings → Privacy & Security** and click **Open Anyway**. It shows for about an hour after the block. Enter your login password.

On macOS 14 and earlier, Control-click the app → **Open** → **Open** instead. Control-click no longer bypasses Gatekeeper on macOS 15.
</details>

## What's new

- On Windows, starting Sync while an old lock file is still being cleaned up no longer stops with "could not read its lock file". Sync reads the lock only after the lock attempt fails, and gives a rival that is deleting the file a moment to finish. If the old lock disappears while Sync reads it, Sync takes the lock instead of saying it is already running ([#87](https://github.com/themark-net/leasegrid-c/issues/87)).
- Android (in source, no APK in this release): **Invite** has **Scan QR**. It reads the short code on the desktop share card, or the join link on the invite page, into the same field. Join still waits for the tap. A code that is not a join link leaves the field as it was ([#77](https://github.com/themark-net/leasegrid-c/issues/77)).
- Android (in source): **Scan QR** asks for the camera before the scanner opens. If you tap **Don't allow**, the screen says to paste the join link or type the short code, with no scanner error first. A fail card with nothing to retry shows only **Dismiss** ([#88](https://github.com/themark-net/leasegrid-c/issues/88)).

## Known issues

- Add folder can return Magic Folder HTTP 500 ([#30](https://github.com/themark-net/leasegrid-c/issues/30), open, parked): the row never says **Up to date**. Mention #30 in your bug report.
- The installers are unsigned, so Gatekeeper and SmartScreen warn. On Windows 11, Smart App Control can block the app and not offer **Run anyway**.
