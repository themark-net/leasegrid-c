# Leasegrid Sync v0.1.13

Friends-and-family build of Leasegrid Sync, the desktop folder-sync window. This cut includes the desktop changes since v0.1.12.

**There is no Android APK in this release.** The one Android change below is in the source only. Only the desktop installers are attached.

The installers are unsigned, so your OS will warn before the first launch.

## Install

| OS | Download | One-liner |
|----|----------|-----------|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04+, Debian 12+, Fedora 36+) | [`Leasegrid_Sync-0.1.13-x86_64.AppImage`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.13/Leasegrid_Sync-0.1.13-x86_64.AppImage) | `chmod +x` it and run it. Needs FUSE (`libfuse2` on Ubuntu). |
| macOS (Intel; Apple Silicon through Rosetta 2) | [`Leasegrid_Sync-0.1.13-macos-x86_64.dmg`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.13/Leasegrid_Sync-0.1.13-macos-x86_64.dmg) | Drag to Applications, then **Open Anyway** (steps below). |
| Windows 10/11 x64 | [`Leasegrid_Sync-0.1.13-win64-setup.exe`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.13/Leasegrid_Sync-0.1.13-win64-setup.exe) | On SmartScreen: **More info → Run anyway**. |
| Windows x64, no setup | [`Leasegrid_Sync-0.1.13-win64.zip`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.13/Leasegrid_Sync-0.1.13-win64.zip) | Unzip and start `leasegrid-sync.exe`. `leasegrid-sync-cli.exe` is the console program, not the window. |

**Checksums:** compare your download with the matching `SHA256SUMS-linux-x86_64`, `SHA256SUMS-macos-x86_64` or `SHA256SUMS-win64` asset on [this release](https://github.com/themark-net/leasegrid-c/releases/tag/v0.1.13) before you run it.

<details>
<summary>macOS: “unidentified developer”: Open Anyway steps</summary>

1. Open the `.dmg` and drag **Leasegrid Sync** onto **Applications**.
2. Double-click **Leasegrid Sync** in Applications. Gatekeeper blocks it (the app is ad-hoc signed, not notarized).
3. Open **System Settings → Privacy & Security** and click **Open Anyway**. It shows for about an hour after the block. Enter your login password.

On macOS 14 and earlier, Control-click the app → **Open** → **Open** instead. Control-click no longer bypasses Gatekeeper on macOS 15.

## What's new

- **Add folder** checks the hosts first. When fewer hosts are connected than your grid needs to store a folder, it says "folder not added. Hosts connected: N of M needed." with "Next: wait until Hosts shows M connected, then Retry Add folder." and does not open the folder picker. If hosts drop while a folder is being added, you get the same line instead of the Magic Folder HTTP 500 text ([#30](https://github.com/themark-net/leasegrid-c/issues/30)).
- The scripted check `leasegrid-sync --dogfood-folder` gets the same hosts check. It waits up to 20 seconds after joining for enough hosts, then exits 1 with the same line ([#30](https://github.com/themark-net/leasegrid-c/issues/30)).
- **Join** refuses a join link or `pb://` address that was cut short (in chat or mail, for example) right away with "Invite furl is malformed." It used to wait about 30 seconds and then say the introducer was unreachable. Ask your inviter for the whole link ([#80](https://github.com/themark-net/leasegrid-c/issues/80)).
- Docs: the installer, dev grid, paid path, AppImage, recovery and Android dogfood guides are now under [`docs/guides/`](https://github.com/themark-net/leasegrid-c/tree/main/docs/guides) ([#87](https://github.com/themark-net/leasegrid-c/issues/87)).
- Android (in source, no APK): the **Scan QR** camera-permission decision moved into one small class with its own test. Nothing changes on screen ([#89](https://github.com/themark-net/leasegrid-c/issues/89)).

## Known issues

- Add folder can still return Magic Folder HTTP 500 when enough hosts are connected ([#30](https://github.com/themark-net/leasegrid-c/issues/30), open). That message names #30. Mention #30 and the **Hosts** line in your bug report.
- The installers are unsigned, so Gatekeeper and SmartScreen warn. On Windows 11, Smart App Control can block the app and not offer **Run anyway**.
