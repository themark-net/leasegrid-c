# Leasegrid Sync v0.1.2

Friends-and-family build of Leasegrid Sync, the desktop folder-sync window. The app is the same as v0.1.1 (version string `0.1.2`); this build fixes the release page and the installer CI around it.
The installers are unsigned, so your OS will warn before the first launch.

## Install

| OS | Download | One-liner |
|----|----------|-----------|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04+, Debian 12+, Fedora 36+) | [`Leasegrid_Sync-0.1.2-x86_64.AppImage`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.2/Leasegrid_Sync-0.1.2-x86_64.AppImage) | `chmod +x` it and run it. Needs FUSE (`libfuse2` on Ubuntu). |
| macOS (Intel; Apple Silicon through Rosetta 2) | [`Leasegrid_Sync-0.1.2-macos-x86_64.dmg`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.2/Leasegrid_Sync-0.1.2-macos-x86_64.dmg) | Drag to Applications, then **Open Anyway** (steps below). |
| Windows 10/11 x64 | [`Leasegrid_Sync-0.1.2-win64-setup.exe`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.2/Leasegrid_Sync-0.1.2-win64-setup.exe) | On SmartScreen: **More info → Run anyway**. |
| Windows x64, no setup | [`Leasegrid_Sync-0.1.2-win64.zip`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.2/Leasegrid_Sync-0.1.2-win64.zip) | Unzip and start `leasegrid-sync.exe`. `leasegrid-sync-cli.exe` is the console program, not the window. |

**Checksums:** compare your download with the matching `SHA256SUMS-linux-x86_64`, `SHA256SUMS-macos-x86_64` or `SHA256SUMS-win64` asset on [this release](https://github.com/themark-net/leasegrid-c/releases/tag/v0.1.2) before you run it.

<details>
<summary>macOS: “unidentified developer” — Open Anyway steps</summary>

1. Open the `.dmg` and drag **Leasegrid Sync** onto **Applications**.
2. Double-click **Leasegrid Sync** in Applications. Gatekeeper blocks it (the app is ad-hoc signed, not notarized).
3. Open **System Settings → Privacy & Security** and click **Open Anyway**. It shows for about an hour after the block. Enter your login password.

On macOS 14 and earlier, Control-click the app → **Open** → **Open** instead. Control-click no longer bypasses Gatekeeper on macOS 15.
</details>

## What's new

- The release page text now comes from `docs/release-notes/<tag>.md` instead of only the auto changelog ([#58](https://github.com/themark-net/leasegrid-c/pull/58), `9e1eb35`).
- Each platform attaches a `SHA256SUMS-*` file for its downloads ([#58](https://github.com/themark-net/leasegrid-c/pull/58)).
- A test keeps `pyproject.toml` and the app version string equal ([#58](https://github.com/themark-net/leasegrid-c/pull/58)).
- A failed installer exit test prints the Tahoe log through an allowlist filter that drops unknown lines and redacts invite and storage secrets ([#60](https://github.com/themark-net/leasegrid-c/pull/60), fixes [#59](https://github.com/themark-net/leasegrid-c/issues/59), `1da2a1d`).
- The paid-upload step retries at most twice on a Windows Tahoe restart race. No app change ([#60](https://github.com/themark-net/leasegrid-c/pull/60)).

## Known issues

- Add folder can return Magic Folder HTTP 500 and never reach **Up to date** ([#30](https://github.com/themark-net/leasegrid-c/issues/30), open, parked). Mention #30 in your bug report.
- Non-blocking follow-ups from the #53 review are not fixed in this build ([#56](https://github.com/themark-net/leasegrid-c/issues/56)).
- Unsigned installers: Gatekeeper and SmartScreen warn. On Windows 11, Smart App Control can block the app with no **Run anyway**.
