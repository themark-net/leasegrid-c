# Leasegrid Sync v0.1.6

Friends-and-family build of Leasegrid Sync, the desktop folder-sync window. This build stops a second window on the same computer, asks before it cancels an open invite, and adds buttons for the logs and a bug report.
The installers are unsigned, so your OS will warn before the first launch.

## Install

| OS | Download | One-liner |
|----|----------|-----------|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04+, Debian 12+, Fedora 36+) | [`Leasegrid_Sync-0.1.6-x86_64.AppImage`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.6/Leasegrid_Sync-0.1.6-x86_64.AppImage) | `chmod +x` it and run it. Needs FUSE (`libfuse2` on Ubuntu). |
| macOS (Intel; Apple Silicon through Rosetta 2) | [`Leasegrid_Sync-0.1.6-macos-x86_64.dmg`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.6/Leasegrid_Sync-0.1.6-macos-x86_64.dmg) | Drag to Applications, then **Open Anyway** (steps below). |
| Windows 10/11 x64 | [`Leasegrid_Sync-0.1.6-win64-setup.exe`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.6/Leasegrid_Sync-0.1.6-win64-setup.exe) | On SmartScreen: **More info → Run anyway**. |
| Windows x64, no setup | [`Leasegrid_Sync-0.1.6-win64.zip`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.6/Leasegrid_Sync-0.1.6-win64.zip) | Unzip and start `leasegrid-sync.exe`. `leasegrid-sync-cli.exe` is the console program, not the window. |

**Checksums:** compare your download with the matching `SHA256SUMS-linux-x86_64`, `SHA256SUMS-macos-x86_64` or `SHA256SUMS-win64` asset on [this release](https://github.com/themark-net/leasegrid-c/releases/tag/v0.1.6) before you run it.

<details>
<summary>macOS: “unidentified developer” — Open Anyway steps</summary>

1. Open the `.dmg` and drag **Leasegrid Sync** onto **Applications**.
2. Double-click **Leasegrid Sync** in Applications. Gatekeeper blocks it (the app is ad-hoc signed, not notarized).
3. Open **System Settings → Privacy & Security** and click **Open Anyway**. It shows for about an hour after the block. Enter your login password.

On macOS 14 and earlier, Control-click the app → **Open** → **Open** instead. Control-click no longer bypasses Gatekeeper on macOS 15.
</details>

## What's new

- A second launch says **Leasegrid Sync is already running. Use the open window.** and does not start another copy.
- Closing the window while an invite is open asks before it quits. **Keep open** is the default.
- **More → Settings** adds **Open logs folder** and **Copy bug-report details**. The copy leaves out invite codes and join links.
- Double-click a folder, or choose **Open folder**, to open it. A missing folder says it is not on this computer any more.
- Reliability and tests: the window remembers its size and place, `sync-ui.log` rotates to `sync-ui.log.1`, quit reaps Tahoe and Magic Folder, and ci-local in a worktree no longer retargets another venv.

## Known issues

- Add folder can return Magic Folder HTTP 500 ([#30](https://github.com/themark-net/leasegrid-c/issues/30), open, parked): the row never says **Up to date**. Mention #30 in your bug report.
- The installers are unsigned, so Gatekeeper and SmartScreen warn. On Windows 11, Smart App Control can block the app and not offer **Run anyway**.
