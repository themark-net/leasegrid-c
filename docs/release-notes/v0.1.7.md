# Leasegrid Sync v0.1.7

Friends-and-family build of Leasegrid Sync, the desktop folder-sync window. A second launch can hand an invite to the open window, shown paths hide your account name, and stopping the app stops Tahoe and Magic Folder.
The installers are unsigned, so your OS will warn before the first launch.

## Install

| OS | Download | One-liner |
|----|----------|-----------|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04+, Debian 12+, Fedora 36+) | [`Leasegrid_Sync-0.1.7-x86_64.AppImage`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.7/Leasegrid_Sync-0.1.7-x86_64.AppImage) | `chmod +x` it and run it. Needs FUSE (`libfuse2` on Ubuntu). |
| macOS (Intel; Apple Silicon through Rosetta 2) | [`Leasegrid_Sync-0.1.7-macos-x86_64.dmg`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.7/Leasegrid_Sync-0.1.7-macos-x86_64.dmg) | Drag to Applications, then **Open Anyway** (steps below). |
| Windows 10/11 x64 | [`Leasegrid_Sync-0.1.7-win64-setup.exe`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.7/Leasegrid_Sync-0.1.7-win64-setup.exe) | On SmartScreen: **More info → Run anyway**. |
| Windows x64, no setup | [`Leasegrid_Sync-0.1.7-win64.zip`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.7/Leasegrid_Sync-0.1.7-win64.zip) | Unzip and start `leasegrid-sync.exe`. `leasegrid-sync-cli.exe` is the console program, not the window. |

**Checksums:** compare your download with the matching `SHA256SUMS-linux-x86_64`, `SHA256SUMS-macos-x86_64` or `SHA256SUMS-win64` asset on [this release](https://github.com/themark-net/leasegrid-c/releases/tag/v0.1.7) before you run it.

<details>
<summary>macOS: “unidentified developer” — Open Anyway steps</summary>

1. Open the `.dmg` and drag **Leasegrid Sync** onto **Applications**.
2. Double-click **Leasegrid Sync** in Applications. Gatekeeper blocks it (the app is ad-hoc signed, not notarized).
3. Open **System Settings → Privacy & Security** and click **Open Anyway**. It shows for about an hour after the block. Enter your login password.

On macOS 14 and earlier, Control-click the app → **Open** → **Open** instead. Control-click no longer bypasses Gatekeeper on macOS 15.
</details>

## What's new

- A second launch with an invite fills the open Join page. You still tick the box and click **Join friendnet**. It does not join by itself.
- Settings, the bug report, and folder banners show a home-relative path instead of your account name.
- `tahoe.log` and `magic-folder.log` rotate to one `.1` backup after 1 MiB when the daemon starts.
- Stopping Leasegrid Sync also stops Tahoe and Magic Folder, including when a service manager sends the stop signal.
- Reliability and tests: a lock left empty by a crash no longer blocks the next launch for about 30 seconds; un-maximize returns the size from before maximize; a bug report scrubs the invite shape the app accepts.

## Known issues

- Add folder can return Magic Folder HTTP 500 ([#30](https://github.com/themark-net/leasegrid-c/issues/30), open, parked): the row never says **Up to date**. Mention #30 in your bug report.
- The installers are unsigned, so Gatekeeper and SmartScreen warn. On Windows 11, Smart App Control can block the app and not offer **Run anyway**.
