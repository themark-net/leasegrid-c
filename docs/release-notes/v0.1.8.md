# Leasegrid Sync v0.1.8

Friends-and-family build of Leasegrid Sync, the desktop folder-sync window. Two small fixes on top of v0.1.7: the newest invite wins, and a refused second launch quits cleanly.
The installers are unsigned, so your OS will warn before the first launch.

## Install

| OS | Download | One-liner |
|----|----------|-----------|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04+, Debian 12+, Fedora 36+) | [`Leasegrid_Sync-0.1.8-x86_64.AppImage`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.8/Leasegrid_Sync-0.1.8-x86_64.AppImage) | `chmod +x` it and run it. Needs FUSE (`libfuse2` on Ubuntu). |
| macOS (Intel; Apple Silicon through Rosetta 2) | [`Leasegrid_Sync-0.1.8-macos-x86_64.dmg`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.8/Leasegrid_Sync-0.1.8-macos-x86_64.dmg) | Drag to Applications, then **Open Anyway** (steps below). |
| Windows 10/11 x64 | [`Leasegrid_Sync-0.1.8-win64-setup.exe`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.8/Leasegrid_Sync-0.1.8-win64-setup.exe) | On SmartScreen: **More info → Run anyway**. |
| Windows x64, no setup | [`Leasegrid_Sync-0.1.8-win64.zip`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.8/Leasegrid_Sync-0.1.8-win64.zip) | Unzip and start `leasegrid-sync.exe`. `leasegrid-sync-cli.exe` is the console program, not the window. |

**Checksums:** compare your download with the matching `SHA256SUMS-linux-x86_64`, `SHA256SUMS-macos-x86_64` or `SHA256SUMS-win64` asset on [this release](https://github.com/themark-net/leasegrid-c/releases/tag/v0.1.8) before you run it.

<details>
<summary>macOS: “unidentified developer” — Open Anyway steps</summary>

1. Open the `.dmg` and drag **Leasegrid Sync** onto **Applications**.
2. Double-click **Leasegrid Sync** in Applications. Gatekeeper blocks it (the app is ad-hoc signed, not notarized).
3. Open **System Settings → Privacy & Security** and click **Open Anyway**. It shows for about an hour after the block. Enter your login password.

On macOS 14 and earlier, Control-click the app → **Open** → **Open** instead. Control-click no longer bypasses Gatekeeper on macOS 15.
</details>

## What's new

- If you open several invites while Leasegrid Sync is already running, the newest one wins. An older invite still waiting to replace the Join page is dropped ([#75](https://github.com/themark-net/leasegrid-c/pull/75), `7e73a64`).
- If you start Leasegrid Sync a second time and the "already running" box is open, stopping that second copy with Ctrl-C, SIGTERM or SIGHUP now exits cleanly (exit code 0) instead of crashing ([#75](https://github.com/themark-net/leasegrid-c/pull/75), `7e73a64`).
- Everything else is the same as v0.1.7.

## Known issues

- Add folder can return Magic Folder HTTP 500 ([#30](https://github.com/themark-net/leasegrid-c/issues/30), open, parked): the row never says **Up to date**. Mention #30 in your bug report.
- The installers are unsigned, so Gatekeeper and SmartScreen warn. On Windows 11, Smart App Control can block the app and not offer **Run anyway**.
