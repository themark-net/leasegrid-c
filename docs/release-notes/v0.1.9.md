# Leasegrid Sync v0.1.9

Friends-and-family build of Leasegrid Sync, the desktop folder-sync window. The desktop app is the same as v0.1.8; this cut ships the Android Invite join-link change (#50) in source.
The installers are unsigned, so your OS will warn before the first launch.

## Install

| OS | Download | One-liner |
|----|----------|-----------|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04+, Debian 12+, Fedora 36+) | [`Leasegrid_Sync-0.1.9-x86_64.AppImage`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.9/Leasegrid_Sync-0.1.9-x86_64.AppImage) | `chmod +x` it and run it. Needs FUSE (`libfuse2` on Ubuntu). |
| macOS (Intel; Apple Silicon through Rosetta 2) | [`Leasegrid_Sync-0.1.9-macos-x86_64.dmg`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.9/Leasegrid_Sync-0.1.9-macos-x86_64.dmg) | Drag to Applications, then **Open Anyway** (steps below). |
| Windows 10/11 x64 | [`Leasegrid_Sync-0.1.9-win64-setup.exe`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.9/Leasegrid_Sync-0.1.9-win64-setup.exe) | On SmartScreen: **More info → Run anyway**. |
| Windows x64, no setup | [`Leasegrid_Sync-0.1.9-win64.zip`](https://github.com/themark-net/leasegrid-c/releases/download/v0.1.9/Leasegrid_Sync-0.1.9-win64.zip) | Unzip and start `leasegrid-sync.exe`. `leasegrid-sync-cli.exe` is the console program, not the window. |

**Checksums:** compare your download with the matching `SHA256SUMS-linux-x86_64`, `SHA256SUMS-macos-x86_64` or `SHA256SUMS-win64` asset on [this release](https://github.com/themark-net/leasegrid-c/releases/tag/v0.1.9) before you run it.

<details>
<summary>macOS: “unidentified developer” — Open Anyway steps</summary>

1. Open the `.dmg` and drag **Leasegrid Sync** onto **Applications**.
2. Double-click **Leasegrid Sync** in Applications. Gatekeeper blocks it (the app is ad-hoc signed, not notarized).
3. Open **System Settings → Privacy & Security** and click **Open Anyway**. It shows for about an hour after the block. Enter your login password.

On macOS 14 and earlier, Control-click the app → **Open** → **Open** instead. Control-click no longer bypasses Gatekeeper on macOS 15.
</details>

## What's new

- Android **Invite** now asks for the desktop's full join link (**Share invite**, then tick **Show full join link (advanced)**). Short codes and web links get a plain explanation instead of a raw error ([#50](https://github.com/themark-net/leasegrid-c/issues/50), `b79d897`).
- Android join, refresh and recovery-import failures say *Couldn't reach your computer.* with one next step; a saved import that could not finish says *Saved on this phone. Couldn't reach your computer to finish.* A link cut short is reported as incomplete ([#50](https://github.com/themark-net/leasegrid-c/issues/50), `b79d897`).
- The Android **Join a shared folder** button stays off until a link is pasted ([#50](https://github.com/themark-net/leasegrid-c/issues/50), `b79d897`).
- Not in this build: joining from the phone with a short code or QR scan ([#77](https://github.com/themark-net/leasegrid-c/issues/77)). Hardening follow-ups: [#78](https://github.com/themark-net/leasegrid-c/issues/78), [#80](https://github.com/themark-net/leasegrid-c/issues/80).
- Everything else is the same as v0.1.8.

## Known issues

- Add folder can return Magic Folder HTTP 500 ([#30](https://github.com/themark-net/leasegrid-c/issues/30), open, parked): the row never says **Up to date**. Mention #30 in your bug report.
- The installers are unsigned, so Gatekeeper and SmartScreen warn. On Windows 11, Smart App Control can block the app and not offer **Run anyway**.
